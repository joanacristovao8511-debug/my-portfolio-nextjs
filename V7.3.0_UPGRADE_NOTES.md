# V7.3.0 — Prisma / Database Performance & Reliability

## Changes
- Added composite indexes for the primary public project ordering/filter path: `[status, featured, createdAt]`.
- Added composite indexes for common skill and experience ordering/filtering: `[category, order]` and `[current, startDate]`.
- Reduced homepage project/skill query payloads with explicit Prisma `select` projections.
- Limited public homepage projects to `status: "active"`, preventing inactive projects from leaking into the public portfolio.
- Limited portfolio knowledge project loading to active projects.
- Preserved the existing Prisma singleton and existing database provider configuration.

## Validation
- Source-level inspection completed.
- ZIP integrity verified after packaging.
- Full dependency installation / production build was not claimed because the prior environment installation attempt timed out.

## Deployment
Run the existing database deployment command (`npm run db:push`) or create/apply a Prisma migration in the deployment environment so the new indexes exist in PostgreSQL.

# V7.2.0 — API Security & Abuse Protection

## Changes
- Added a dependency-free, best-effort in-memory rate limiter for public write/AI endpoints.
- `/api/chat`: 20 requests per minute per client address, with `429` + `Retry-After`.
- `/api/feedback`: 30 requests per minute per client address for feedback writes/deletes.
- Added request `Content-Length` guards for chat and feedback payloads.
- Added `Cache-Control: no-store` to rate-limit and malformed-request responses where appropriate.
- Preserved public visitor chat and feedback functionality; admin feedback reads remain protected by `requireAdmin()`.
- Kept all project, experience, skill, and profile APIs behind `requireAdmin()`.
- Documented the limiter's per-instance nature; production multi-instance deployments should use a shared rate-limit store for strict global enforcement.

## Validation
- Source-level inspection completed.
- ZIP integrity verified.
- Full dependency install/build was not claimed because the environment's prior npm install attempt timed out.

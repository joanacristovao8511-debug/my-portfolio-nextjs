# V6.4.0 — Performance & Server/Client Boundary Optimization

## Changes

- Switched the portfolio landing page to Framer Motion `LazyMotion` + `domAnimation` with `m.*` primitives to reduce the initial animation feature payload.
- Lazy-loaded the portfolio chatbot as a separate client chunk.
- Converted `ProjectPreview` from a hydrated client component to a server component; native browser scrolling now replaces the ResizeObserver/state logic.
- Added `loading="lazy"` and `decoding="async"` to project preview imagery where appropriate.
- Added short-lived ISR caching (`revalidate = 60`) to public portfolio and case-study routes instead of forcing every request through dynamic rendering.
- Added `content-visibility: auto` to below-the-fold portfolio sections to defer rendering work until needed.
- Throttled header scroll state updates with `requestAnimationFrame` to avoid repeated React state work during fast scrolling.
- Preserved the existing design, navigation, project behavior, and case-study structure.

## Validation

- Source-level checks performed after modification.
- ZIP integrity verified after packaging.
- A full production build is not claimed unless dependency installation and `next build` complete successfully in the validation environment.

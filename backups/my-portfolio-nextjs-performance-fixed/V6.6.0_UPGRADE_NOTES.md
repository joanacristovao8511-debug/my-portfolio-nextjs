# V6.6.0 — SEO & Content Architecture

## Focus
Strengthen crawlability, metadata quality, social sharing, structured data, and canonical URL handling without changing the portfolio's visual design.

## Changes
- Added centralized `lib/site-config.ts` for public site identity and URL configuration.
- Expanded root metadata with canonical URL, Open Graph image, Twitter card, Googlebot directives, and category metadata.
- Added a real 1200x630 `public/og-image.png` social preview asset.
- Expanded JSON-LD from a single Person node to a Person + WebSite graph.
- Added project-level canonical URLs and richer social metadata.
- Added project CreativeWork JSON-LD and BreadcrumbList JSON-LD.
- Improved sitemap to use database-backed `updatedAt` timestamps and hourly revalidation.
- Kept `/admin/` and `/api/` excluded from crawling.
- Documented public SEO environment variables in `.env.example`.

## Content integrity
No fabricated project metrics, clients, rankings, or achievements were introduced. SEO metadata is derived from existing portfolio/profile/project data or explicit environment configuration.

## Validation
- Source-level checks performed.
- ZIP integrity will be verified before delivery.
- Full production dependency installation/build is not claimed unless it completes successfully in the available environment.

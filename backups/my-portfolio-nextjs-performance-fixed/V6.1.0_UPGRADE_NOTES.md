# V6.1.0 — Frontend Architecture Refactor

## Goal
Reduce the coupling and size of the public portfolio client component without changing the public design or portfolio content.

## Changes
- Extracted portfolio domain types and static presentation data into `components/portfolio-data.ts`.
- Extracted the project preview/scroll measurement behavior into `components/project-preview.tsx`.
- Extracted theme state, scroll state, active-section observation, mobile-menu behavior, project derivation, skill grouping, and theme class derivation into `components/use-portfolio-landing.ts`.
- Kept `PortfolioLanding` responsible primarily for composing the public UI.
- Preserved existing project ordering and skill-category normalization behavior.
- Preserved existing theme persistence and chatbot integration.

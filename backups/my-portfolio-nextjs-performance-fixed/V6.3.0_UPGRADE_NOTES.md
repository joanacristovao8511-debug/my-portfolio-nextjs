# V6.3.0 — Senior-Level Project / Case Study Experience

## Goal
Turn project detail pages from a generic portfolio detail view into evidence-driven engineering case studies without inventing metrics or changing the existing Prisma project model.

## Changes
- Reworked `/projects/[slug]` into a structured case-study experience.
- Clear hierarchy: context → problem → approach → architecture → ownership → outcome.
- Added sticky case-study navigation on desktop.
- Added technology grouping from project skills + tags with duplicate normalization.
- Preserved only data that exists in the database; no fabricated metrics or claims.
- Added clearer live-product and source-code actions.
- Improved preview presentation and alt text.
- Added related active projects to keep visitors exploring the portfolio.
- Improved project-specific Open Graph metadata.
- Added a proper `notFound()` path for missing projects.
- Kept the page server-rendered and avoided adding client-side JavaScript.

## Validation
- Source reviewed after rewrite.
- ZIP archive integrity should be checked before delivery.
- Full production build was not claimed unless dependency installation and `next build` completed successfully in the execution environment.

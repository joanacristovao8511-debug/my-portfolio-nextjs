# V7.0.0 — Release Candidate Reliability & Cleanup

## What changed

### Admin action reliability
- Admin dashboard action props for profile and experience are now required because the current admin page wires every action.
- Removed the misleading `"This action is not connected yet."` fallback.
- `runAction()` now understands the existing server-action `{ success, error }` contract instead of treating every resolved promise as success.
- Failed create-project and create-experience actions no longer close their create forms.
- Successful actions still refresh the dashboard.

### API resilience
- Added error handling to `GET /api/admin/content` so database/runtime failures return the project's standard API error response instead of an unhandled exception.

### Dead-code cleanup
- Removed the unused duplicate `app/admin/alt-actions.ts` server-action module. The canonical `app/admin/actions.ts` is the only admin mutation implementation.

## Validation

- Source-level audit completed.
- ZIP integrity verified after packaging.
- Full dependency install / TypeScript / ESLint / Next.js production build were not claimed because this environment did not have `node_modules`, and the prior dependency installation attempt timed out.

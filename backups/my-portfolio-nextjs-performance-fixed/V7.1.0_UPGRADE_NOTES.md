# V7.1.0 — Admin Session UX & Runtime Hardening

## Changes

- Hardened the admin dashboard Sign out control with an explicit in-flight state.
- Prevented duplicate sign-out submissions while the NextAuth session is being cleared.
- Added `aria-busy` and disabled-state feedback for accessibility and clearer UX.
- Added a user-visible error notice if the client-side sign-out request rejects.
- Preserved the `/admin/login` callback destination and the existing NextAuth JWT session configuration.

## Validation

- Source-level inspection completed.
- ZIP integrity verified after packaging.
- A full dependency install/build was not claimed because the environment previously timed out during `npm ci`.
